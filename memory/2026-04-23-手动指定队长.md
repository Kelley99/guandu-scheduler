# 手动指定队长功能

## 日期
2026-04-23

## 需求
支持手动指定某个成员担任队长（如"花开不开花"没有属性数据也能指定为队长）

## 实现
### 前端 (templates/index.html)
- 新增 `manualCaptains` ref，存储 {B1:'', B2:'', ...}
- 步骤3新增UI：6个下拉框选择B1-B6队长，支持清空（-- 自动 --）
- 重新分配时清空 manualCaptains
- `runAssignment` 传递 `manual_captains` 参数

### 后端 (app.py)
- `assign_members()` 新增 `manual_captains` 参数
- 逻辑：
  1. 先处理手动指定的队长（直接填入b_assign，跳过HP排序）
  2. 从排序列表中排除已被手动指定的成员
  3. 剩余位置按原规则自动分配

## 服务
端口5001，需手动重启生效
