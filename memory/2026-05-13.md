## 经验教训

### Vue 3 Composition API 变量暴露规则
- **声明 ≠ 可用**：`const xxx = ref()` 只是声明，还必须在 `setup()` 的 return 中暴露
- 新增变量时必须做两件事：①声明 ②return
- 排查方法：对比 `const xxx = ref()` 列表与 `return {}` 列表，找差集

### edit 工具注意事项
- `edit` 操作的 `oldText` 替换边界可能吞掉相邻行，替换后必须验证语法
- 特别是函数定义行（`def xxx():`）紧接 `try/except` 块时容易被吞

### gc_manager 调试技巧
- Vue errorHandler 显示红色渲染错误提示框
- Flask 日志：`flask.log`
- 重启：`pkill -f "python3 app.py"; nohup python3 app.py > flask.log 2>&1 &`
