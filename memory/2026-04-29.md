**关键发现**：
- 7个 alert 弹窗顺序：1,2,3,6,7,4,5 — **这是正常的**！
  - 1→2→3→6→7 = 同步路径（setup() → return → mount）
  - 4→5 = 异步路径（init() 是 async，mount 后才执行）
- Vue mount 成功（alert 7 弹了），但页面空白 → **模板渲染失败**
- 使用 `vue.global.prod.js`（生产模式）会**静默吞掉模板渲染错误**

**发现的 Bug**：
1. **`getStatLabel` 未在 return 中暴露** — 函数在 setup() 中定义了但没 return，模板中却引用了 `{{ getStatLabel(name) }}`，调用 undefined 函数导致渲染报错
2. **`app.config.errorHandler` 缺失** — Vue prod 模式默认不报告渲染错误

**已执行的修复 (18:52)**：
1. 将 `getStatLabel` 添加到 setup() 的 return 对象中
2. 将 `.mount('#app')` 改为先 `const app = createApp({...})` 再 `app.config.errorHandler` 再 `app.mount('#app')`，添加错误处理弹出 alert

**等待用户反馈**：刷新 http://localhost:5001/ 后页面是否正常显示，或有 "Vue渲染错误" alert
