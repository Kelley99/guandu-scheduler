Kelley 报告 gc_manager 考勤模块打开后出现 3 条错误：
- "Cannot read properties of undefined (reading 'length')"

### 调查过程
1. 定位错误在考勤模块（考勤 → 进入后出现）
2. 检查 `/Users/kelley/.qclaw/workspace-agent-29b6e205/templates/index.html`
3. 搜索所有 `.length` 使用位置
4. 发现 `attOcrNames` 在模板第 687 行被使用，但在 JavaScript 中未定义

### 根本原因
变量 `attOcrNames` 在模板中被引用（`v-if="attOcrNames.length"`），但在 JavaScript 代码中没有声明和初始化。

### 修复方法
在 `index.html` 第 1198 行（`attOcrData = ref([])` 之后）添加：
```javascript

```

- 端口: 5001
