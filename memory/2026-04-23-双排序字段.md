## 需求
同时支持按"步兵生命值"和"六维属性总和"两种字段排序

## 实现

### 后端 (app.py)
1. `parse_stats_table()` - 新增解析"六维属性总和"列到 `total` 字段
2. `assign_members()` - 新增 `sort_by` 参数，支持 'hp' 或 'total'
3. `assign_api()` - 接收 `sort_by` 参数传递

### 前端 (templates/index.html)
1. 步骤2弹窗下拉选项显示 "HP / 六维总和" (如 "1227 / 5858")
2. 步骤3新增排序字段选择（单选框）
3. 步骤4预览表格新增"六维总和"列
4. 新增 `getStatTotal()`、`getStatLabel()` 函数
