### 16:18 - 服务进程僵持问题（compaction flush）

**问题**：Kelley测试OCR返回空，`/api/ocr_test` 也 404

**根因**：Flask 进程僵持（Gateway restart 触发的 SIGTERM 被忽略），kill -9 也未能完全清理

**解决**：Gateway stop → 进程僵持依旧 → `lsof -ti:5001` 找真实PID → `kill -9 PID` → Gateway start 拉起干净进程 → `/api/ocr_test` 正常返回

**教训**：Gateway restart 不等于进程重启，僵持时需手动 lsof + kill -9
