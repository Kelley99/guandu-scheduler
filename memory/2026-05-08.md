# 方案二（数据库分组多租户系统）详细评估

## 一、核心方案设计

### 数据结构

```sql
-- groups 表：团队配置
CREATE TABLE groups (
    id INTEGER PRIMARY KEY,
    url_path TEXT UNIQUE,        -- URL路径，如 lingxiao, baimo, 450
    display_name TEXT,          -- 显示名称，如 "凌霄"、"白沫"
    export_password TEXT,        -- 导出密码（每个团队独立）
    ocr_limit INTEGER DEFAULT -1,  -- OCR次数限制（-1=无限）
    ocr_used INTEGER DEFAULT 0,   -- 已用次数
    created_at DATETIME
);

-- purchases 表：充值记录
CREATE TABLE purchases (
    id INTEGER PRIMARY KEY,
    group_id INTEGER,
    amount REAL,                 -- 充值金额
    ocr_add INTEGER,             -- 额外OCR次数
    note TEXT,                   -- 备注
    created_at DATETIME
);

-- attributes 表新增字段
ALTER TABLE attributes ADD COLUMN group_id INTEGER DEFAULT 1;
```

### URL 路由设计

| 团队 | URL | 说明 |
|------|-----|------|
| 默认/凌霄 | `/` 或 `/lingxiao/` | 主页面 |
| 白沫 | `/baimo/` | 白沫团队 |
| 450 | `/450/` | 450团队 |

访问流程：用户访问 `https://xxx.com/450/` → Flask 中间件解析 group_id=2 → 所有查询自动加 `WHERE group_id = 2`

### 核心功能

1. **数据隔离**：所有查询自动加 group_id 过滤
2. **独立密码**：每个团队独立导出密码
3. **额度管理**：OCR 次数限制与充值记录
4. **管理后台**：查看各团队使用情况

### 生产环境推荐

| 方案 | 配置 | 月费用 | 并发能力 | 适用场景 |
|------|------|--------|----------|----------|
| 轻量 | 1核512M | $5 | ~10人 | 小团队 2-3 个 |
| 标准 | 1核1G | $10 | ~30人 | 5-10个团队 |
| 扩展 | 2核2G | $20 | ~100人 | 10+团队 |

### 软件依赖

| 软件 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 运行环境 |
| Flask | 最新 | Web 框架 |
| SQLite | 内置 | 数据库（轻量够用） |
| gunicorn | 可选 | 生产环境 WSGI 服务器 |

### 数据库扩展说明

- **SQLite**：适合 10 个团队以内、数据量 < 10 万条
- **MySQL/PostgreSQL**：如果未来需要支持更多团队或更高并发，可以切换，SQLAlchemy 已支持多数据库
- 当前阶段 SQLite 完全够用，无需额外安装数据库服务

## 四、与方案一（独立部署）对比

| 维度 | 方案一（独立部署） | 方案二（数据库分组） |
|------|-------------------|---------------------|
| 开发时间 | ~1h（复制+改配置） | 4-5h |
| 维护成本 | 高（每个实例单独维护） | 低（单实例统一管理） |
| 数据库 | 独立 .db 文件 | 共用一个 .db |
| 扩展性 | 需手动创建新目录/端口 | 后台加一行即可新增团队 |
| 数据迁移 | 容易（复制文件） | 需 SQL 脚本 |
| 费用 | N × $5/月 | $5-10/月 |
| OCR 额度管理 | 无法实现 | 完整实现 |

# 方案二（数据库分组多租户系统）详细评估

## 一、核心方案设计

### 数据结构

```sql
-- groups 表：团队配置
CREATE TABLE groups (
    id INTEGER PRIMARY KEY,
    url_path TEXT UNIQUE,        -- URL路径，如 lingxiao, baimo, 450
    display_name TEXT,          -- 显示名称，如 "凌霄"、"白沫"
    export_password TEXT,        -- 导出密码（每个团队独立）
    ocr_limit INTEGER DEFAULT -1,  -- OCR次数限制（-1=无限）
    ocr_used INTEGER DEFAULT 0,   -- 已用次数
    created_at DATETIME
);

-- purchases 表：充值记录
CREATE TABLE purchases (
    id INTEGER PRIMARY KEY,
    group_id INTEGER,
    amount REAL,                 -- 充值金额
    ocr_add INTEGER,             -- 额外OCR次数
    note TEXT,                   -- 备注
    created_at DATETIME
);

-- attributes 表新增字段
ALTER TABLE attributes ADD COLUMN group_id INTEGER DEFAULT 1;
```

### URL 路由设计

| 团队 | URL | 说明 |
|------|-----|------|
| 默认/凌霄 | `/` 或 `/lingxiao/` | 主页面 |
| 白沫 | `/baimo/` | 白沫团队 |
| 450 | `/450/` | 450团队 |

访问流程：用户访问 `https://xxx.com/450/` → Flask 中间件解析 group_id=2 → 所有查询自动加 `WHERE group_id = 2`

### 核心功能

1. **数据隔离**：所有查询自动加 group_id 过滤
2. **独立密码**：每个团队独立导出密码
3. **额度管理**：OCR 次数限制与充值记录
4. **管理后台**：查看各团队使用情况
