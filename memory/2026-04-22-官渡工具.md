# 2026-04-22 - 官渡自动分配工具

## 完成项目
构建了完整的网页端官渡自动分配工具。

## 核心文件
- `app.py` - Flask后端 (端口5001, 调试模式)
- `templates/index.html` - Vue3网页前端
- `auto_assign.py` - 命令行版本(备用)

## 功能
1. 导入属性表（步兵生命值）
2. 导入人员名单（30+10）
3. 自动匹配成员（支持顿号/逗号转换）
4. 手动确认未匹配成员
5. 按规则分配到B/D列
6. 预览并导出Excel

## 分配规则
- B1=排序1, B2=排序2, D1=排序3, D9=排序4
- B3-B6=排序5-8
- D2-D8, D10-D16=随机分配
- D17-D24=低HP(默认<900)随机分配
