## Ngrok 进程不稳定问题
- 08:29 ngrok 进程启动后马上退出（exec code 0），隧道无法维持
- 原因：ngrok 前台运行时 session 关闭进程就退了
- 解决：用 nohup 后台驻留（`nohup ngrok http 5002 &`），PID 50885
- 教训：ngrok 必须用 nohup 或类似方式后台运行，否则 exec session 结束进程就挂
