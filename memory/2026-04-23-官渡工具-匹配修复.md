# 官渡工具匹配状态修复

## 问题
手动匹配确认后，未匹配数量没有更新（仍显示3人未匹配）

## 原因
`confirmMatches`函数把所有项都标记到`nameMap`，但没有从`unmatched`数组中移除已匹配项

## 修复
```javascript
const confirmMatches = () => {
    const stillUnmatched = [];
    for (const item of unmatched.value) {
        if (item.manualMatch) {
            nameMap.value[item.original] = item.manualMatch;
        } else {
            stillUnmatched.push(item);
        }
    }
    unmatched.value = stillUnmatched;  // 更新未匹配列表
    showMatchModal.value = false;
};
```
