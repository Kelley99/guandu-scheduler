## Flask+Vue 项目调试 - axios 挂起问题

### 问题现象
- Vue 前端发送请求后挂起，Promise 既不 resolve 也不 reject
- Flask 后端日志显示请求完成并返回数据
- 前端 axios 调用收不到响应

### 根因分析
- axios 从 CDN `unpkg.com` 加载，在某些网络环境下可能被阻塞或响应极慢
- 导致 axios 实例初始化或请求发送阶段卡住

### 解决方案
- 将所有 axios 调用替换为原生 `fetch`
- fetch 是浏览器原生 API，不依赖外部 CDN
- 替换要点：
  - `axios.get(url)` → `fetch(url).then(r => r.json())`
  - `axios.get(url, {params})` → `fetch(url + '?' + new URLSearchParams(params)).then(r => r.json())`
  - `axios.post(url, data)` → `fetch(url, {method:'POST', headers:{'Content-Type':'application/json'}, body:JSON.stringify(data)}).then(r => r.json())`
  - `axios.post(url, formData)` → `fetch(url, {method:'POST', body: formData})` (FormData 自动设置 Content-Type)
